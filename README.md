URL Shortener\
A simple and efficient URL Shortener built using Node.js, Express, MongoDB, and EJS. This web application allows users to generate short URLs, track visit history, and manage links securely.

🚀 Features\
✅ Shorten URLs – Convert long URLs into short, shareable links.\
✅ User Authentication – Sign up and log in to manage your shortened URLs.\
✅ Role-Based Access Control (RBAC) – Admins can view all shortened URLs, while normal users can only see their own.\
✅ Visit Tracking – Monitor the number of times a short URL is accessed with timestamped visit history.\
✅ JWT Authentication – Secure user sessions using JSON Web Tokens (JWT).\
✅ EJS Templating – Dynamic UI rendering with EJS views.

🛠 Tech Stack\
Backend: Node.js, Express.js\
Database: MongoDB with Mongoose ODM\
Authentication: JWT, Cookies\
Frontend: EJS\
Other Tools: UUID, Cookie Parser
